# Python Keylogger Lab

## Objetivo

Desenvolver um laboratório em Python para estudar eventos de teclado, manipulação de strings, tratamento de exceções e comunicação SMTP.

## Tecnologias utilizadas

- Python
- pynput
- smtplib
- email.mime
- threading

## Ambiente

| Componente | Utilização |
|---|---|
| Windows | Sistema operacional |
| Python | Linguagem de programação |
| pynput | Eventos de teclado |
| Gmail SMTP | Comunicação por e-mail |
| threading.Timer | Temporizadores |

## Experimentos realizados

- Implementação de listener para eventos de teclado.
- Manipulação e concatenação de strings.
- Tratamento de teclas especiais.
- Utilização de variáveis globais.
- Tratamento de exceções.
- Implementação de temporizadores.
- Estudo de comunicação SMTP.
- Autenticação e comunicação com servidor de e-mail.

## Conceitos estudados

- Funções e escopo de variáveis.
- Estruturas condicionais.
- Manipulação de strings.
- Tratamento de exceções (`try` e `except`).
- Eventos e callbacks.
- Execução de tarefas programadas.
- Protocolos de comunicação.
- Autenticação SMTP e STARTTLS.

## Segurança

- Executar experimentos somente em ambientes próprios e autorizados.
- Não coletar credenciais ou informações privadas de terceiros.
- Proteger credenciais e senhas de aplicativo.
- Não armazenar informações sensíveis diretamente no código-fonte.
